# Guia de Download do LibreOffice

## Opção 1: Site Oficial (Recomendado)

Acesse: **https://pt-br.libreoffice.org/download/**

Clique no botão verde **"Baixe já"** e escolha a versão para Windows.

---

## Opção 2: Link Direto

Se o site não carregar, use este link direto:

**Windows 64-bit:**
https://download.documentfoundation.org/libreoffice/stable/26.2.2/win/x86_64/LibreOffice_26.2.2_Win_x86-64.msi

---

## Após instalar:

1. Execute o arquivo `.msi` baixado
2. Aceite os termos de licença
3. Clique em "Avançar" até terminar a instalação
4. Reinicie o computador

---

## Para o servidor funcionar:

O LibreOffice precisa estar no PATH do sistema.

Após instalar, adicione ao PATH:
- Abra "Variáveis de Ambiente" no Windows
- Edite a variável "Path" 
- Adicione: `C:\Program Files\LibreOffice\program`

---

## Download Automático:

Você também pode executar o arquivo `download_libreoffice.bat` na pasta do projeto para baixar automaticamente.

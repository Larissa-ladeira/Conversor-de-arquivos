# Como Instalar o LibreOffice

## Para Windows - Download Direto

1. Acesse: **https://pt-br.libreoffice.org/download/**
2. Clique em **"Baixe já"** (versão Windows x86-64)
3. Ou use este link direto:
   https://download.documentfoundation.org/libreoffice/stable/26.2.2/win/x86_64/LibreOffice_26.2.2_Win_x86-64.msi

## Após baixar e instalar:

1. Execute o instalador `.msi` 
2. Aceite os termos e clique em "Avançar" até instalar
3. Não precisa configurar nada especial

## IMPORTANTE - Adicionar ao PATH (para o servidor funcionar):

1. Procure pelo menu Iniciar
2. Digite "Variáveis de ambiente" 
3. Clique em "Editar variáveis de ambiente do sistema"
4. Clique em "Variáveis de Ambiente..."
5. Em "Variables do sistema", procure "Path" e clique em "Editar"
6. Clique em "Novo" e adicione:
   `C:\Program Files\LibreOffice\program`
7. Clique em OK em tudo

## Para testar se está instalado:

1. Abra o Prompt de Comando (cmd)
2. Digite: `libreoffice --version`

Se aparecer a versão, está funcionando!

## Problemas?

Se ainda der erro 404, o servidor pode estar com problemas temporários.
Tente acessar por outro mirror ou aguarde um pouco.

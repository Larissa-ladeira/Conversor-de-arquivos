# 📄 TopConvert – Conversor de Arquivos

> Aplicação web intuitiva e prática desenvolvida para facilitar a conversão de arquivos de forma rápida e segura diretamente no navegador.

🔗 **Acesse o projeto online:** [Ver Projeto no Render](INSIRA_O_LINK_DO_RENDER_AQUI)

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias modernas de desenvolvimento front-end e bibliotecas especializadas em manipulação de documentos:

* **Linguagens:** HTML5, CSS3 e JavaScript (Vanilla)
* **Manipulação de PDF:** jsPDF e PDF.js
* **Estilização & UX:** Interface responsiva com design limpo e navegação fluida
* **Hospedagem & Deploy:** [Render](https://render.com/)

---

## ✨ Funcionalidades Principais

* **🖼️ Imagens para PDF:** Converte múltiplos arquivos de imagem (como PNG, JPG/JPEG) em um único documento PDF organizado.
* **📚 Extração de Texto para EPUB:** Permite extrair o conteúdo textual de arquivos PDF e estruturá-los no formato EPUB para leitura digital.
* **⚡ Processamento Local/Rápido:** Realiza as operações de conversão com agilidade, otimizando o fluxo do usuário.
* **🌙 UX Moderna:** Interface responsiva, amigável e adaptada para uma excelente experiência de uso em diferentes dispositivos.
